# Rezonants Website

The corporate website, digital product showcase, multi-language interface, and AI assistant experience for **Rezonants** (`rezonants.com`), built with React, Vite, and Supabase.

## Development

```bash
npm install
npm run dev
```

## Verification & Build

```bash
npm run lint
npm run typecheck
npm run test:chatbot
npm run build
```
